# Tipos sanguíneos e compatibilidade

Os tipos sanguíneos são A, B, AB e O, cada um com fator Rh positivo (+) ou negativo (-).

## Doador universal
Quem tem sangue O negativo (O-) é chamado de doador universal de hemácias: pode doar hemácias para pessoas de todos os tipos. Por isso o estoque de O- é o que mais costuma faltar.

## Receptor universal
Quem tem sangue AB positivo (AB+) é o receptor universal de hemácias: pode receber de todos os tipos.

## Regras gerais de hemácias
- O- doa para todos; recebe só de O-.
- O+ doa para O+, A+, B+ e AB+.
- A+ doa para A+ e AB+; A- doa para A+, A-, AB+ e AB-.
- B+ doa para B+ e AB+; B- doa para B+, B-, AB+ e AB-.
- AB+ doa só para AB+; AB- doa para AB+ e AB-.

Qualquer tipo sanguíneo é bem-vindo: todos são necessários nos estoques.
